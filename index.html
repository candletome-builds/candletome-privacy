Support

For help with CandleTome Reader, email bek.ar.nariman@gmail.com.

Report a problem

Tell us your device model, iOS or iPadOS version, app version, and what you were doing when the issue occurred. For import issues, include the file format. Please leave private books, notes, and payment details out of your message.

Restore a purchase

If your version offers the paid import feature, select Restore Purchases in the app menu using the same Apple Account you used to buy the feature. This restores import access. Keep separate copies of any files you want to import again.

For App Store billing or refund requests, use Apple’s Report a Problem.
